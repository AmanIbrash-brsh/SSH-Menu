# SSH Menu

Быстрое меню SSH для администраторов: по горячей клавише открывается список серверов из `~/.ssh/config`, ищешь по паре букв и подключаешься. Всё управляется с клавиатуры. В меню видно, жив ли сервер и пускает ли он по ключу, а в боковой панели показано его состояние: нагрузка, диски, обновления, упавшие сервисы.

Работает на любом Linux, в любом терминале и окружении: GNOME, KDE, Hyprland, Sway и других. Построено на [fzf](https://github.com/junegunn/fzf), `ssh` и Python 3. Отдельной базы нет: источник данных — ваш `~/.ssh/config`.

## Возможности

- **Подключение**: `Enter` — ssh, `Alt+T` — ssh сразу в tmux-сессию `main` (переживает обрыв связи). Можно ввести `user@host`, которого нет в списке.
- **Статус в списке**: ● зелёный — порт отвечает, красный — нет, жёлтый — хост за ProxyJump. Рядом пометка, если вход по ключу не работает: `password`, `no access`, `host key changed`.
- **Панель сведений**: адрес, ключ, ping, ОС, uptime, load, память, диски (заполненные подсвечиваются), число обновлений (отдельно security), «нужна перезагрузка», упавшие systemd-юниты, docker. Данные кэшируются на 10 минут. На сетевых устройствах и git-серверах без shell команды не выполняются.
- **Файлы**: `Alt+U` — загрузить на хост или сразу на несколько, `Alt+D` — скачать (обзор папок прямо в меню) в `~/Загрузки/<хост>/`, `Alt+F` — открыть хост в файловом менеджере (sftp).
- **Несколько хостов**: `Tab` — отметить, `Alt+X` — выполнить команду на всех (одинаковые ответы склеиваются), `Alt+B` — broadcast (tmux-панели, ввод идёт во все), `Alt+K` — разослать SSH-ключ.
- **Группы и PROD**: группы и пометка PROD хранятся комментариями в `~/.ssh/config`. `Alt+←/→` показывает одну группу, `Alt+P` переключает «все / без PROD / только PROD». Окно PROD-сессии подкрашивается красным, а массовые действия на PROD-хостах требуют подтверждения.
- **Правка**: `Alt+N` — мастер нового хоста, `Alt+E` — открыть хост в редакторе, `Alt+G` — группа, `Alt+R` — PROD. Перед каждым изменением `~/.ssh/config` делается бэкап.
- `Alt+W` — веб-интерфейс хоста, `Alt+Y` — скопировать `user@host:port`, `Ctrl+R` — перепроверить всё, **`Alt+H` — все клавиши**.

## Установка

```bash
git clone https://github.com/AmanIbrash-brsh/SSH-Menu.git
cd SSH-Menu
./install.sh
```

Права root не нужны: всё ставится в `~/.local`. Нужны `ssh` и `python3` (3.8 или новее), а fzf установщик найдёт сам. Если в системе fzf старше 0.63 (например, в Ubuntu 24.04 стоит 0.44), установщик скачает свежий fzf только для меню и проверит его sha256. Системный fzf он не трогает.

Обновление: `git pull && ./install.sh`. Удаление: `./uninstall.sh` (настройки и история остаются).

Необязательные программы, без которых отключается только соответствующая функция:

| Программа | Для чего |
|---|---|
| `tmux` | `Alt+B` broadcast |
| `wl-clipboard` / `xclip` / `xsel` | `Alt+Y` копирование |
| `zenity` / `kdialog` | окно выбора файлов для `Alt+U` (без него выбор идёт через fzf) |
| `libnotify` (`notify-send`) | уведомления |

Пакеты в разных дистрибутивах:

```bash
sudo apt install openssh-client python3 tmux xclip wl-clipboard zenity libnotify-bin  # Debian / Ubuntu
sudo dnf install openssh-clients python3 tmux wl-clipboard zenity libnotify            # Fedora
sudo pacman -S openssh python tmux wl-clipboard zenity libnotify                       # Arch
```

## Горячая клавиша

Запускать стоит команду `ssh-menu-popup`: она открывает меню в отдельном окне. В самом терминале можно просто набрать `ssh-menu`. Окно меню получает класс `ssh-menu`, по нему его удобно сделать плавающим.

**GNOME**: Настройки → Клавиатура → Комбинации клавиш → Дополнительные комбинации → `+`, команда `~/.local/bin/ssh-menu-popup`. В GNOME `Super+S` по умолчанию открывает быстрые настройки, поэтому выберите другую клавишу или сначала освободите эту.

**KDE Plasma**: Параметры системы → Клавиатура → Комбинации клавиш → Добавить → Команда, `~/.local/bin/ssh-menu-popup`.

**Hyprland** (`hyprland.conf`):
```
bind = SUPER, S, exec, ~/.local/bin/ssh-menu-popup
windowrulev2 = float, class:^(ssh-menu)$
windowrulev2 = size 1400 780, class:^(ssh-menu)$
windowrulev2 = center, class:^(ssh-menu)$
```

**Sway**:
```
bindsym $mod+s exec ~/.local/bin/ssh-menu-popup
for_window [app_id="ssh-menu"] floating enable, resize set 1400 780
```

Меню открывается плавающим окном, а после подключения на Hyprland и Sway окно становится обычным, как любой терминал.

## Как хранятся группы и пометки

Всё лежит в `~/.ssh/config` в виде комментариев прямо над строкой `Host`. ssh их игнорирует, так что конфиг остаётся обычным:

```
# group: Proxmox
# env: prod
# url: https://10.0.0.11:8006
Host pve1
    HostName 10.0.0.11
    User root
```

- `group` — группа (цветная колонка, фильтр `Alt+←/→`);
- `env: prod` — PROD: красная пометка, красное окно, подтверждение массовых действий;
- `url` — адрес для `Alt+W`; если его нет, меню спросит адрес при первом нажатии и сохранит.

Блок `Host *` с настройками по умолчанию держите **последним**: ssh берёт первое найденное значение. Новые хосты из `Alt+N` вставляются перед ним.

Совет: добавьте в `Host *` мультиплексирование. Тогда повторные подключения, панель сведений, `Alt+X` и файлы работают мгновенно:

```
Host *
    ControlMaster auto
    ControlPath ~/.ssh/sockets/%C
    ControlPersist 10m
```
(и один раз выполните `mkdir -p ~/.ssh/sockets && chmod 700 ~/.ssh/sockets`)

## Настройки

Файл `~/.config/ssh-menu/config` создаётся при установке, все параметры в нём закомментированы:

| Параметр | Что задаёт | По умолчанию |
|---|---|---|
| `SSHM_TERMINAL` | терминал для окна меню и broadcast | первый найденный: kitty, foot, alacritty, wezterm, ghostty, konsole, ptyxis, gnome-terminal, xfce4-terminal, xterm |
| `SSHM_TERMINAL_ARGS` | доп. опции терминала, например `"-o font_size=12"` | — |
| `SSHM_BROWSER` | браузер для `Alt+W` | `xdg-open` |
| `SSHM_FILES` | файловый менеджер для `Alt+F` | nautilus, иначе `xdg-open` |
| `SSHM_EDITOR` | редактор для `Alt+E` | `$EDITOR`, micro, nano, vim |
| `SSHM_FZF` | путь к fzf | скачанный установщиком или системный |

## Где лежат данные

`~/.local/state/ssh-menu/`:
- `history` — частота подключений (по ней сортируется список);
- `status.tsv`, `auth.tsv`, `stats/` — кэш статусов, проверки ключей и сведений о системе;
- `backups/` — 20 последних копий `~/.ssh/config`.

Проверка входа по ключу выполняется не чаще раза в 12 часов, а также по `Ctrl+R` и после `Alt+K`. Она открывает обычное ssh-соединение с `BatchMode` и командой `true`. Сведения о системе собираются только чтением: `/proc`, `df`, `systemctl --failed`, `apt-get -s` / `dnf -C check-update`, `docker ps`.

## Структура

```
bin/ssh-menu          меню (bash + fzf)
bin/ssh-menu-popup    открыть меню в отдельном окне терминала
lib/ssh_hosts.py      разбор и правка ~/.ssh/config, проверки, панель сведений
lib/term.sh           запуск окна в любом терминале
share/                конфиг tmux для broadcast, ярлык для меню приложений
```
